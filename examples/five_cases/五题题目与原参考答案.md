# 多肽副产物诊断 · 通俗版练习题（5 题，含参考答案）

> 用途：拿去别处考人或考 AI。**第一部分只给题面**，可以直接复制；第二部分是参考答案与评分点。
> 所有肽序列与总分子量都换过，不对应书里原来的例子，但每个副反应的化学出处仍是 Yang 2016（页码写在答案里）。
> 统一口径：文中质量都是**单同位素中性质量**；m/z 按 `[M+nH]ⁿ⁺ = (中性质量 + n×1.007276) / n` 换算；误差一律「实测 − 理论」。

# 第一部分 · 题面

## 第 1 题（MALDI 多了 147）

我们做了一个 C 端酰胺的六肽 **H-Ser-Tyr-Gly-Arg-Lys-Ala-NH₂**（Fmoc 固相合成，Lys 侧链先用 Mtt 保护，Mtt 用 TFA/TES/DCM 脱掉，之后在 DIC/HOBt 下偶联 Fmoc-Phe，最后哌啶脱 Fmoc、TFA 切割）。

MALDI-TOF 打出来主峰 **m/z 827.45**（[M+H]⁺）。按序列算理论值应该是 680.38。

**问：多了 147 是什么东西？在哪个位置？能不能直接说是哪个结构？**

## 第 2 题（ESI 每个电荷多 7）

一个七肽酸 **H-Gly-Asp-Ser-Pro-Lys-Glu-Ala-OH**，RP-HPLC 纯化时流动相里含甲醇，收集液又用含 TFA 的甲醇-水溶解后冻干（同批样还用甲酸、乙酸体系处理过）。

ESI-HRMS 主峰 **m/z 359.1743（z = 2）**，理论 [M+2H]²⁺ 应该是 352.1665。

**问：每个电荷多 7.0078，折成中性是多少？可能发生了什么？只有一个可能吗？**

## 第 3 题（两个峰差 15.99，z = 2）

一个 C 端酰胺的七肽 **H-Cys-Gly-Tyr-Ser-Cys-Arg-Ala-NH₂**，1 位和 5 位形成二硫键（环状）。这批样在 DCC/HOBt/DIEA 条件下和甘氨酰胺反应过。

同一张 LC-MS 图上出现两个挨得很近的峰：**A 峰 m/z 378.6494，B 峰 m/z 394.6355，两个都是 z = 2**。A 峰和起始二硫肽的理论值对得上。

**问：B 峰是什么？差多少个 Da？还有没有别的结构能给出几乎一样的质量？怎么分？**

**问：这个「没加 DCC」的信息该怎么用？能不能就此断定 B 不是三硫？应该怎么继续查？**

## 第 5 题（MALDI 多了 56）

一个 C 端酰胺的六肽 **H-Gly-Trp-Tyr-Cys-Met-Ala-NH₂**，合成后处理时用 MTBE 萃取/沉淀过。

MALDI-TOF 主峰 **m/z 785.35**（[M+H]⁺），理论 729.28。

**问：多了 56 是什么？为什么这种肽特别容易中招？低分辨的 56 能不能直接当成某个结构？**

# 第二部分 · 参考答案与评分点

## 第 1 题参考答案

**一句话**：多出来的是**一个苯丙氨酸残基**（+C₉H₉NO = +147.0684），但**位置不能只凭质量定**——至少有两个位置给出完全相同的质量。

**算账**
- 理论中性质量 679.3766，[M+H]⁺ = 680.3838；实测 827.45 → 差 **+147.07**（MALDI 只到 0.01，误差按 ±0.1 用）。
- +147.0684 与「多一个 Phe 残基」一致；Phe 游离氨基酸是 165.0790，差的是**残基**（165.0790 − H₂O），不要拿游离氨基酸去对。

**两个并列候选（质量完全相同，必须并列）**
1. **N 端多偶联一个 Phe**：Lys 参与使 Nα-Fmoc 提前脱掉，下一轮 Phe 又偶联到已经空出来的 N 端 → H-Phe-Ser-Tyr-Gly-Arg-Lys-Ala-NH₂。
2. **Lys 侧链 ε-NH₂ 被 Fmoc-Phe 酰化**：ε-氨基提前游离，被 Phe 封端 → 侧链多一个 Phe。

书中（第 10 章 §10.2.1，p.239–242，Fig. 10.5）在这个 Lys 体系里实际拿到的是**第 1 种**（模板 H-Lys(H-Phe)-Ala-NH₂ → H-Phe-Lys(H-Phe)-Ala-NH₂），并给了 Mtt 路线 20:80、Alloc 路线 35:65 的比例；但**质量本身分不开这两种位置**，这一点书里也讲得很清楚。

**怎么验证**
- **MS/MS**：N 端多 Phe 会让整条 b 系列整体移位；ε-N 酰化只在含 Lys 的碎片上体现，b/y 定位不同。
- **酶解**：Lys 侧链被酰化后 Trypsin 切不动，酶切图谱会变。
- **Edman 测序**：直接看 N 端第一个残基是不是 Phe。
- 顺带：Mtt 与 Alloc 两条路线的比例不同，说明这和侧链保护基策略有关，换保护基能压低副产物。

**不能下的结论**：不能写「827.45 就是 N 端多一个 Phe」——那是把质量吻合当成结构确证。

**评分点（缺一扣分）**：① 说出 +147.0684 = 一个 Phe 残基（不是游离氨基酸）；② 至少并列 N 端多掺与 Lys-εN 酰化两个位置；③ 明确低分辨质量不能定位置；④ 给出 MS/MS / 酶解 / Edman 中至少两种验证；⑤ 指出与保护基策略相关。

## 第 2 题参考答案

**一句话**：中性质量多了 **+14.0157**，是**甲酯化**（−COOH → −COOCH₃）；但**侧链甲酯和 C 端甲酯质量一样**，不能只留一个。

**算账**
- 理论中性 702.3184，[M+2H]²⁺ = 352.1665；实测 359.1743 → 每个电荷差 7.0078 → 中性差 **+14.0157**（正好一个 CH₂）。
- 产物中性 716.3341。

**并列候选**
1. **Asp / Glu 侧链甲酯化**：这条序列的 Asp 在 2 位、Glu 在 6 位，两处侧链羧基都可能。
2. **C 端羧基甲酯化**（这题 C 端是游离酸，正好是甲酯化的靶点）。
3. 另外还有「树脂上残留甲醇被带进 TFA 切割液」这条路径，同一 +14 也能造成，出处与条件不同。

书中第 8 章 §8.1.2（p.204–207，Fig. 8.3；并见 14.3.1，p.315）给的就是这个通例：甲醇接触 + 酸（TFA/甲酸/乙酸）→  Asp/Glu 侧链和/或 C 端甲酯化，书里直接写「+14 amu」。

**怎么验证**
- **MS/MS**：C 端甲酯化会让 y 系列/C 端碎片整体 +14；侧链 Asp 甲酯化只影响含 Asp 的碎片。
- **碱处理 / 羟胺处理后再测**：甲酯能被碱水解，ΔM 消失；这是最快的判别。
- **换流动相**：去掉甲醇重跑一遍，看峰是否消失（同时排除工艺引入）。

**不能下的结论**：不能只报「甲酯化」一个位点；也不能因为「+14 也可能是甲基化」就混着说——甲基化（+CH₂ 在 N/O 上）与甲酯化元素组成相同，要靠反应条件与化学行为区分。

**评分点**：① 换算正确（每电荷 ×2，+14.0157 = CH₂）；② 侧链甲酯与 C 端甲酯并列；③ 指出甲醇 + 酸这个条件；④ 给碱水解/换流动相/ MS/MS 至少两种验证；⑤ 不把质量吻合当结构确证。

## 第 3 题参考答案

**一句话**：B 峰 = 起始二硫肽 **+ 一个硫原子**（+S = **+31.9721**），即**二硫 → 三硫（trisulfide）**。

**算账**
- A 峰 m/z 378.6494（z=2）对应中性 755.2843，与起始二硫肽理论值一致。
- 两峰 m/z 差 15.9860，**乘回电荷数 ×2 = 31.9721 Da** —— 只换中性质量而忘了乘 z，是最常见的错。
- 产物中性 787.2564。

**几乎同质量的竞争者**
- **+2O = +31.9898**（两个氧，例如 Cys 磺酸/SO₃H、或 Met 亚砜再氧化成砜）与 +S 只差 **0.0178 Da**（中性）；在 z=2 上只差 **0.0089 m/z**。
- 这意味着：**低分辨、或分辨率不够的高分辨都会把两者混成一个峰**。要分开需要 R ≳ 2 万以上，或者靠 MS/MS / 化学实验。
- 另外，如果参照态写的是**自由 SH 肽**而不是二硫肽，同一个三硫产物应记 **+S − H₂ = +29.9564**，不要拿 +31.9721 去对，这是参照态错误。

书中第 13 章 §13.2.2（p.303–308，Fig. 13.11）：cystine 衍生物 + 甘氨酰胺在 DCC/HOBt/DIEA 下生成三硫，最高约 10%，**没有 DCC 就不生成**。

**怎么验证**
- **高分辨复核**：把 +S 与 +2O 分开（看质量亏损）。
- **还原实验**：DTT/TCEP 还原后三硫会变回二硫并放出 H₂S，质量回到 A 的位置；单纯的氧化修饰不会这样。
- **硫同位素图形**：多一个 S，M+2 同位素峰的相对强度会明显升高。
- **MS/MS**：三硫在碰撞中容易丢 S。

**不能下的结论**：B 峰「质量对得上三硫」不等于结构确证；也不能忽略与 +2O 的 0.0178 Da 之争。

**评分点**：① 峰差乘回 z（15.9860×2）；② 说出 +S = 三硫；③ 并列 +2O 竞争者并给出 0.0178 Da；④ 提醒参照态（+S vs +S−H₂）；⑤ 给还原/高分辨/MS/MS 中至少两种验证。

## 第 4 题参考答案

**一句话**：这条阴性信息必须**参与判断、写进排除理由**，但它**不能反过来证明 B 一定是别的东西**。

**怎么用这条信息**
1. 书中那条「DCC 介导生成三硫」的路径，在明确没加 DCC 时应当**降级/排除**，并且理由要写出来（「你明确否定了 DCC，而该路径要求 DCC」），而不是悄悄忽略。
2. 但三硫**不是只有 DCC 一条路**：空气氧化、溶剂/试剂中的过氧化物、光照、其他缩合剂（BOP、HBTU 等）都能给。所以 B 峰仍在是**化学上合理的**，不能直接判「不是三硫」。
3. 反过来，如果高分辨确认了就是 +S，那说明**污染或替代路径**存在——要查试剂批次（DCC 是否真没加、器皿是否共用）、溶剂过氧化物、光照，以及样品前处理是否引入氧化。

**继续查的顺序**
- 先高分辨确认是 +S 还是 +2O（0.0178 Da 之争）。
- 再做还原实验（三硫还原后质量回落 + 放 H₂S）。
- 再查试剂/溶剂/器皿的阴性对照（空白批、无肽对照）。
- 最后才谈「哪条路径为主」。

**不能下的结论**：不能因为「没加 DCC」就写「不是三硫」；也不能因为「B 峰弱」就写「可忽略」——低强度副产物在工艺放大里照样是问题。

**评分点**：① 阴性证据要显式进入排除理由；② 同时指出三硫有多条非 DCC 路径；③ 给出继续排查顺序（高分辨 → 还原 → 试剂/溶剂对照）；④ 不把「弱峰」当「不存在」。

## 第 5 题参考答案

**一句话**：多了 **+56.0626 = +C₄H₈**，最可能是**叔丁基化**（tert-butylation，芳环/吲哚/硫上的亲电取代），MTBE 后处理是常见来源。

**算账**
- 理论中性 728.2774，[M+H]⁺ = 729.2847；实测 785.35 → 差 **+56.07**（MALDI 取 0.01，按 ±0.1 用）。
- +C₄H₈ = 56.0626；注意叔丁基化是「上去一个 t-Bu、掉一个 H」，所以净增 C₄H₈，不是 C₄H₉（57.0704）。

**为什么这条肽容易中招**
- 序列里有 **Trp、Tyr、Cys、Met** —— 吲哚、酚、硫都是富电子位点，酸性条件下（TFA 残留 + MTBE 中的过氧化物/微量叔丁醇）容易发生叔丁基阳离子进攻。
- 书中第 14 章（MTBE 相关条目）把这种修饰归到 **+C₄H₈ = 56.0626**，并提示位点在 Cys/Tyr/Trp/Met 这类残基上。

**低分辨的 56 能不能直接定结构**
- 不能。名义 56 附近至少有三个元素组成：**C₄H₈ = 56.0626**、**C₃H₄O = 56.0262**、**C₃H₆N = 56.0498**；MALDI 的 ±0.1 分辨不足以区分。
- 必须先做高分辨，看质量亏损落在哪一档。

**怎么验证**
- **HRMS**：区分 C₄H₈ / C₃H₄O / C₃H₆N。
- **MS/MS**：看修饰落在哪个残基（含 Trp/Tyr 的碎片 +56）。
- **工艺对照**：同一批样改用不接触 MTBE 的后处理，看 +56 是否消失；检查 MTBE 是否含过氧化物（碘化钾试纸）。
- **加清除剂**：后处理加少量还原剂/避光，观察是否被抑制。

**不能下的结论**：不能只写「+56，叔丁基化」；也不能因为「+56 也可能是两个 +28」就混过去——两个 CH₂ 也正好 56.0626，但化学上不会这么成对发生，要说明理由而不是并列了事。

**评分点**：① 换算 +56.0626 = C₄H₈（不是 C₄H₉）；② 指出 MTBE/叔丁基来源与 Trp/Tyr/Cys/Met 富电子位点；③ 说明低分辨 56 有多个元素组成、必须高分辨；④ 给工艺对照或清除剂实验；⑤ 不把质量吻合当结构确证。
